After two random armies are picked — what happens?

The app already has an "Army Selection" reveal screen. Should random matchup reuse it, or get its own result view?

A

Reuse the existing reveal screen (recommended)

Show the same "Army Selection Ready" screen that manual selection uses — hidden behind a Reveal button, showing both armies with player 1 / player 2 markers. Zero new UI to build.

B

Show result immediately on the same tab (no separate screen)

The two picked armies appear inline below a "Randomize!" button on the home tab — no navigation, no reveal animation. Simpler, but less dramatic.

C

New dedicated result screen with re-roll

A separate screen that shows the two armies and a "Re-roll" button to randomize again without going back. More capable but more work to build.
